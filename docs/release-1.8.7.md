# FrpDeck 1.8.7

本版主要修复长期运行的内存累积，并完善飞牛安装、授权和操作反馈。

- 修复 Docker 空闲连接累积。每次操作结束释放连接，容器发现和迁移内部仍可复用连接。
- 修复内网密码限速、保存失败回滚及迁移记录未保存时仍继续操作的问题。
- 删除或调整服务时持久保存 Lucky 清理任务，失败和重启后继续重试，只处理本安装拥有的规则；回滚必须核对后才提示恢复完成。
- 飞牛新安装在向导中设置管理员账号和密码。已有未初始化安装可在飞牛应用设置中补填；已有账号不会被覆盖。
- 已签发的飞牛体验保留原截止时间，不因包版本暂时不一致误停线路；永久授权不随软件版本失效。
- 授权页减少无必要的远端查询，并显示激活阶段、请求编号和重试说明。网络异常时请保留原数据，用同一码重试，不要重复购买。
- 改善断线、保存和同步结果提示；增加未保存表单提醒；配置导出与完整备份明确区分。
- 帮助页增加“感谢 bbong9 提供的技术支持。”。

## 更新前

备份完整持久数据目录（含隐藏文件）、Compose 和部署参数。普通配置导出不包含账号、两步验证、探针凭据及历史数据，不能替代完整备份。主容器如承载 SSH 隧道，请从 NAS 本地管理入口更新。

飞牛用户通过对应 FPK 更新；Docker 用户更新镜像并重建容器，保留原数据目录、端口、环境参数和 Docker socket。已有 1.8.4/1.8.5 探针无需因本次主程序修复重装。

升级不重新计算 60 天体验，不增加席位，也不会修改永久授权。清空数据或更换 Docker 引擎属于绑定身份变化，需恢复原数据或处理换绑。

回退请同时恢复升级前的完整数据和匹配镜像；不要只换镜像后继续写入新数据。

## 验证范围

自动化与测试设备验收结果见发布记录。买家真实网络、NAS 长时间资源变化作为上线后的持续观察项。Lucky 与外部管理工具同时编辑同一主规则的冲突、应用内完整备份恢复及诊断包继续作为后续改进。
