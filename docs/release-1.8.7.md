# FrpDeck 1.8.7

本版重点改善长期运行稳定性、飞牛安装和授权体验。

## 更新内容

- 修复长期运行时 Docker 连接未释放导致的内存持续增长。
- 飞牛全新安装支持在安装向导中设置管理员账号，安装后可直接登录。
- 优化飞牛应用状态检测，减少短时响应异常造成的“未启用”误报。
- 修复升级过程中体验状态判断异常的问题，保留原体验截止时间和已购买授权。
- 完善 Lucky 规则清理与失败重试，提高配置保存和旧容器迁移的可靠性。
- 加强登录防护，改善断线、保存、同步和激活结果提示，增加未保存修改提醒。
- 明确配置导出与完整备份的区别，更新安全依赖。

## 升级提示

- 升级前请备份完整应用数据及部署配置，普通配置导出不能替代完整备份。
- 正常升级保留原账号、配置和授权，请继续使用原密码登录；体验不会重新计时。
- 保留旧数据手动安装时，向导中填写的新密码不会覆盖已有账号，请使用原密码。
- 已有 1.8.4／1.8.5 探针无需为本次主程序更新重装。
- Docker 用户拉取目标版本后需重建容器，保留原数据目录、端口和 Docker socket；飞牛应用中心版本以实际显示为准。
- 主容器承载 SSH 隧道时，请通过 NAS 本地管理入口更新。回退时恢复升级前的完整数据与对应镜像。
