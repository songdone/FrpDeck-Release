# 购买后激活与授权恢复

购买后，在 FrpDeck「授权」页粘贴完整兑换码，核对版本与设备名额后确认激活。首次兑换需要联网，已保存的永久授权在本机验证。

## 已付款但未激活

- 提示订单尚未同步时，请稍后用同一兑换码重试。
- 提示服务繁忙或网络超时时，请保留原数据目录，按页面提示等待后重试，不必重复购买。
- 同一安装与 Docker 环境恢复原授权，不会重复占用设备名额。
- 不要通过清空数据或重装 Docker 尝试解决激活问题，这会改变绑定身份。

仍无法完成时，请通过[官网](https://frpdeck.playsong.cn/)联系作者，提供订单号、错误提示，以及页面显示的请求编号（如有）。不要在公开反馈中发布兑换码、授权码、机器码或密码。

## 升级与换机

保留原数据目录和 Docker 环境，正常升级、重建容器不影响永久授权，飞牛体验继续按原截止时间计算。清空数据或更换设备后，请先恢复完整备份；确需换机时联系作者处理绑定。

授权服务维护不要求重装 FrpDeck 或探针，已有永久授权继续有效。
