# FrpDeck 1.8.5 更新说明

本次更新把「买授权」接进了应用里的授权页：可以直接打开商品页下单，拿到兑换码后在本机激活，不用再复制机器码发给作者。

## 新增

- **授权页可直接购买**：授权页顶部新增专业版、家庭版两个入口，点开就是官方店铺的商品页，价格和权益以商店结算为准。
- **兑换码在本机激活**：粘贴收到的兑换码，应用会先显示这个码是专业版还是家庭版、还剩几个名额，确认之后才真正激活。本机机器码由应用自己识别，不需要手工填写，也不需要发给商家。
- **家庭版可分次绑定**：一个家庭版兑换码最多绑定 3 台 NAS，可以一台一台加，不必一次凑齐。保留原安装数据与 Docker 环境时，用原兑换码可恢复授权，不占新名额。清空数据或更换 Docker 后，请恢复原数据或联系作者审核换绑。
- **升级与名额提示**：已确认专业版可以升级为家庭版；家庭版兑换码不会被误当成降级覆盖。名额用完时会明确提示联系作者处理换绑。
- **已购授权显示名额**：授权页会显示当前已绑定几台、总共几台；权益被暂停时提示新增绑定已停止，已激活的永久授权仍可离线使用。
- **帮助说明改写**：家庭版怎么分次激活、购买和换绑怎么联系作者、活动资格码和购买兑换码的区别，都在授权页的「关于授权」里。

## 流量分析页改版

NAS 详情的流量分析换成新的卡片布局：

- 顶部一条汇总：公网合计、下载到 NAS、从 NAS 上传、已归属应用占比。
- 应用流量列表：可在合计/下载/上传之间切换，按所选方向排序；点每一行右侧的箭头，展开该应用的下载、上传和占公网合计比例；超过 5 项可展开全部。
- 流量识别情况：已归属应用的字节与占比、覆盖条，以及未归属流量单独说明，不把没识别到的流量强行归给系统。
- 流量趋势：下载与上传双色堆叠，附方向图例。

统计口径、探针计量和账本都没有变化，只是展示方式调整。

## 升级

**主程序**：更新镜像后刷新页面即可。本版不改变授权存储格式，保留原数据目录就能继续用。

**授权服务**：兑换码激活需要授权服务同步更新。

- 授权服务已更新：购买入口、兑换码激活、名额显示全部可用。
- 授权服务还没更新：购买入口和原来 `FD2.` 开头的授权码激活照常可用；粘贴兑换码会提示服务端暂不支持，不会消耗兑换码。活动资格码和飞牛体验不受影响。

升级前请备份完整数据目录，包括授权、线路和网关连接文件。

## 说明

- 本版新增的购买入口指向官方店铺，收费与飞牛官方无关。
- 真实付款订单的完整闭环和多台真实 NAS 的分次激活，需要在正式发售之后按实际订单继续验证。
- 官网图片保持原有香槟金深色版本。飞牛应用中心以实际审核上架版本为准。
