# FrpDeck 1.8.6 更新说明

本次更新优化 NAS 公网流量展示，让流量来源、上传下载和采集状态更清楚，并改善手机端操作体验。

- 恢复流量占比环图，将未归属流量与其余已识别应用分开展示。
- 修复切换上传、下载时环图合计变化的问题，应用占比按对应方向计算。
- 优化异常数据提示：明细存在重叠时暂停显示占比；探针离线、版本过旧或权限不足时直接提示。
- 完善流量趋势的采样与时间说明，改善长应用名称、手机端按钮和弹窗布局。
- 优化授权购买页面，修正授权恢复说明。升级或重建容器时，请保留原数据目录。

## 升级提示

- 从 1.8.4 / 1.8.5 升级：更新 FrpDeck 主程序即可，NAS 和服务器探针无需为本次更新重装。
- 仍使用 1.8.0 NAS 探针时，需要更新探针后使用新版公网统计；保留原密钥、回调地址和部署参数。
- 保留原数据目录，线路、用户设置、授权和历史流量继续保留。不要清空数据后重新部署。
- 同一安装与 Docker 环境可用原兑换码恢复授权。清空数据或更换 Docker 后，请恢复原数据或联系作者审核换绑。
- 由 FrpDeck 承载远程 SSH 通道时，更新主容器会暂时中断连接，请通过 NAS 本地管理页面操作。

本次不改变流量账本与授权存储格式。更新不会重算此前存在口径重叠的历史数据。飞牛应用中心的版本以实际审核上架结果为准。
