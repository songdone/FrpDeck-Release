# 体验与授权

- **基础版**永久免费：一条线路，服务数量不限，包含 Lucky 域名联动、免费 fn-knock 对接、监控、流量统计、消息推送和线路测试。
- **专业版、家庭版**为永久授权，包含后续版本更新。专业版首发价 8.8 元、正常售价 18 元，可激活 1 台 NAS；家庭版首发价 18 元、正常售价 28 元，可激活 3 台 NAS。两者功能相同。
- **飞牛 60 天体验**：从飞牛应用中心安装的 FrpDeck 可免费体验专业版 60 天，到期后恢复为基础版，固定一条保留线路，其余停用但配置保留，基础版不可切换。可提前预选；未选时优先已启用默认线路，再选最早添加且启用的线路；全部关闭则保持关闭。通过 Docker 命令或 Compose 部署的 FrpDeck 不提供体验。
- **购买与激活**：在应用「授权」页打开商品页，购买后粘贴兑换码，核对版本和设备名额再激活，无需发送机器码。首次兑换需要联网，激活后的永久授权可离线验证。家庭版可分次激活最多 3 台 NAS；已有 FD2 授权码仍可使用。
- **恢复与换绑**：保留原数据和 Docker 环境，升级或重建容器不影响授权。清空数据后请先恢复原数据；更换 NAS 或 Docker 环境时，联系 [@Play_6uos](https://t.me/Play_6uos)审核换绑，不会自动释放旧设备名额。

授权的激活、换绑及活动资格说明以应用内「授权」页和[官网](https://frpdeck.playsong.cn/)为准。
