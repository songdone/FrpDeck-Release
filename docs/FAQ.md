# 常见问题

**是否需要购买 VPS？**

使用 frp 中转时，需要自己的 VPS（安装 frps）和 Lucky。家里有可用的公网 IPv6 时，也可以只用 NAS 上的 Lucky。FrpDeck 不提供 VPS、域名和流量。

**切换线路后还能用原来的域名吗？**

每条线路使用各自的域名，切换后请访问新线路的域名；多条线路同时开启时，可分别使用各自的域名。

**docker.sock 后面的 `:ro` 是否表示只读？**

不是。映射后 FrpDeck 可以管理本机 Docker（例如停止、启动容器），`:ro` 不限制这些操作。该映射用于发现容器、迁移旧的 frpc 容器和生成机器码；只使用基础版时可以删除，此时无法激活授权。

**升级或重建容器后需要重新购买吗？**

不需要。保留原数据目录，授权继续有效。清空数据目录或更换 Docker 后机器码会改变，请联系作者换绑。请勿在公开的 Issues 中粘贴授权码或机器码。

**专业版和家庭版有什么区别？**

功能相同。专业版可激活 1 台 NAS，家庭版可激活 3 台 NAS。

**支持哪些设备？**

镜像支持 amd64、arm64、arm/v7 架构的 NAS 和 Linux 主机。amd64 和 arm64 已实际运行验证，arm/v7 尚未在实体设备上验证。

**初始密码文件为什么不见了？**

首次设置管理员后，初始密码失效，文件随之删除。忘记密码时，在数据目录中新建名为 `reset-admin` 的空文件并重启容器，然后在日志中查看新的初始密码；两步验证和「仅允许局域网访问」会同时关闭。

**活动结束后，已兑换的授权还能用吗？**

能。截止时间前兑换成功的授权是永久授权，验证无需联网，不受活动结束影响。

**清空数据后能重新领取活动授权吗？**

不能。同一 Docker 环境在所有活动中只能领取一份授权。
