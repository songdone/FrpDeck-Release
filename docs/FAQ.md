# 常见问题

**是否需要购买 VPS？**

常规 frp 中转模式需要自己的 VPS/frps 与 Lucky。具备可用公网条件时，也可使用 NAS 上的 Lucky 直接访问。FrpDeck 不提供网络线路、域名和流量套餐。

**切换线路后可以继续使用原域名吗？**

每条线路使用对应的域名，切换后打开新线路的域名；同时开启多条线路时，可分别使用它们的域名。当前不提供同一域名自动跟随线路变更 DNS 的能力。

**飞牛应用中心已经上架了吗？**

尚未获得官方上架确认。Releases 中提供的是开发者手动安装测试 FPK，当前版本完整 fnOS 生命周期验收仍待完成。

**Docker socket 的 `:ro` 是否表示只读权限？**

不表示 Docker API 只读。该接口可进行停止、启动等容器管理操作；用于容器发现和迁移。长期仅使用基础版时可从 Compose 删除挂载；FD2 授权必须读取 Docker 引擎编号。

**换容器或升级后要重新购买吗？**

付费授权永久有效，包含后续更新。保持原数据目录与安装标识；硬件、Docker 标识或数据丢失导致机器码变化时，通过作者渠道对接换码。不要在公开 Issues 中粘贴授权码或机器码。

**家庭版和专业版功能不同吗？**

产品功能相同，专业版授权 1 台 NAS，家庭版授权 3 台 NAS。首发价格与截止日期见仓库首页和官网。

**支持哪些设备？**

镜像提供 amd64、arm64、arm/v7，但架构支持不等于所有 NAS 都已实测。当前 amd64 已在极空间 NAS 运行核验，arm64、arm/v7 尚未做本版真实硬件运行验收；fnOS 实际验证范围见本版本发布说明。

**为什么初始密码文件不见了？**

首次管理员设置成功后，初始密码失效并移除。后续使用已设置的管理员账号。重置步骤请按完整部署教程操作，并先备份数据。

**活动结束后已兑换授权怎样使用？**

期限内首次兑换成功后保存的是永久 FD2，日常离线校验，活动结束仍然有效。只有到期未兑换的资格失效。保留原安装数据及同一 Docker 引擎；机器码变化时恢复备份或联系作者审核。

**重置数据是否可以重新领取？**

同一 Docker 引擎全站只取得一份活动授权。新安装编号不能得到第二份活动授权；软件标识仍不能保证真实个人或物理硬件唯一。
