# FrpDeck 1.8.4 更新说明

本次更新改善了 NAS 公网流量的可读性，并修好了几个已知的少算场景。

## 改进

- **下载和上传分开看**：NAS 公网流量环形图新增下载、上传汇总和各自明细，趋势图按方向拆成双色堆叠并带图例，趋势标题会标注统计是从什么时候开始的，避免把装完之后的量看成全天。
- **出站流量归类更准**：NAS 主动下载、同步、更新时用的本地端口是随机的，过去只能落进「其他」。现在按目的端口归类到 HTTPS、HTTP、QUIC、DNS、NTP；「其他」改名为「NAS 自身联网」，说明这部分主要是 NAS 自己发起的下载、网盘同步、系统更新和 BT。
- **穿透业务单独标记**：本机 Lucky 的对外端口和相关服务端口标为穿透业务，卡片显示「其中穿透业务 X，占 N%」，剩下的明确写成 NAS 自身联网或未识别。
- **Docker 端口显示容器名**：桥接容器过去只显示「端口 52888」，现在能看到对应容器名。
- **frps 重启不再少算**：用面板累计值变小判断 frps 重启过，重启后当天计数直接整段记账，不再把重启前那一整段算丢。
- **跨天重置不摊分**：计数重置又跨天时整段记到当天，不再把今天归零后的量按时间摊到前一天。
- **网卡总量对照**：NAS 探针上报物理网卡累计收发，面板显示「同期网卡总量 / 公网统计 / 占比」，公网统计超过网卡总量时会提示可能有回环或重复计入。这一项只做对照，不参与业务账本。

## 升级

- **主程序**：更新镜像后刷新页面即可。上下行、穿透标记、frps 重启校验、跨天不摊分、Docker 端口名都只需要更新主程序。
- **NAS 探针**：出站按目的端口分类和网卡对照需要新探针。旧探针不上报这两项，页面会安静地不显示，不会报错，也不影响原有总量。需要这两项时拉取新探针镜像并重建容器，只重启不会换镜像。

升级前请备份完整数据目录。
