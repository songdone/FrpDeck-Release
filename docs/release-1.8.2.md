# FrpDeck 1.8.2 更新说明

本次更新改善了流量统计与 Lucky 连接体验，并提升配置保存和日常运行的稳定性。

- 修复使用 NAS 本地 Lucky 时，部分服务流量无法正常显示的问题。
- 修复部分旧版 Lucky 的反向代理兼容问题。
- 优化流量来源说明，便于区分 NAS 公网流量与服务流量。
- 改善配置保存与异常恢复。
- 优化登录安全和线路运行稳定性。

**升级提示**：已有 1.8.1 探针可继续使用；仍在使用 1.8.0 NAS 探针时需要更新。请保留原密钥与数据目录，升级前做好完整备份。

回退到 1.8.1 或更早版本时，请恢复升级前的完整备份，确保原有登录信息可用。

[安装与升级说明](https://frpdeck.playsong.cn/guide.html)
