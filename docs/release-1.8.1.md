# FrpDeck 1.8.1 更新说明

本次更新改善了 NAS 公网流量统计与历史记录展示，提升不同网络环境下的使用体验。

- 分别展示 NAS 公网流量与服务流量，统计来源更清楚。
- 改善重启和采集恢复后的统计连续性。
- 优化 IPv6、容器及应用端口的流量识别。
- 修复部分 Lucky 域名规则同步的兼容问题。
- 飞牛应用名称统一为“FrpDeck 内网穿透管家”。

**升级提示**：使用 1.8.0 NAS 探针的用户，请同时更新主程序和 NAS 探针。保留原密钥、回调地址与数据目录，升级前做好完整备份。旧 VPS 探针的基础监控功能可继续使用。

更新探针时，请拉取新版镜像并保留原参数重建容器，仅重启容器不会完成更新。首次采集后会逐步显示统计数据。回退时请恢复升级前的完整备份。

飞牛应用中心以实际可用版本为准。
