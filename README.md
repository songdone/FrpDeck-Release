# FrpDeck 版本记录

FrpDeck 是面向 NAS 的 frp 图形化管理面板。本仓库用于公开版本更新记录和收集反馈，不包含应用源码，也不再提供安装包、Compose 文件或手动部署下载。

**安装与更新请通过飞牛应用中心，搜索 FrpDeck。** 各渠道的更新节奏可能不同，请以应用中心显示为准。

- [完整版本记录](CHANGELOG.md)
- [GitHub Releases](https://github.com/songdone/FrpDeck-Release/releases)
- [官网](https://frpdeck.playsong.cn/)
- [问题反馈](https://github.com/songdone/FrpDeck-Release/issues)

当前版本记录：**1.7.5**。

本应用含付费功能，收费与飞牛官方无关。基础版永久免费，专业版与家庭版的功能及授权说明以应用内授权页和官网为准。

## 分发方式调整

官网与本仓库仅公开版本记录和说明，历史安装附件已停止公开分发。已安装用户请保留原数据目录，通过原安装渠道维护更新。

官网和 GitHub 的版本记录不代表所有分发渠道已经同步更新。
